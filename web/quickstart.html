Installation

安装

  1. Download the package matching your distribution from GitHub Releases. 从 GitHub Releases 下载适合你发行版的安装包。
  2. Install the package. 安装下载好的包。

    Ubuntu / Linux Mint

    cd ~/Downloads
sudo apt install ./smooth-scroll_*.deb

    Fedora

    cd ~/Downloads
sudo dnf install ./smooth-scroll-*.rpm
  3. Start using your mouse wheel. smooth-scroll.service starts immediately and is enabled at boot. 直接开始使用鼠标滚轮。smooth-scroll.service 会立即启动，并随系统开机自启。

If you do not see a package for your distribution in Releases, build from source on GitHub using the repository instructions.

如果 Releases 中没有适合你发行版的安装包，请到 GitHub 按仓库说明从源码编译。

How To Use

如何使用

Start with normal wheel scrolling, then use the following controls when you need to stop inertia, bypass smoothing, or switch into a special mode.

先像平常一样滚动鼠标滚轮。需要停止惯性、绕过平滑处理，或进入特殊模式时，再使用下面这些控制。

  1. Smooth Scroll

    Use the wheel normally. The daemon converts each wheel burst into a smooth motion curve.

    正常使用滚轮即可。daemon 会把每段滚轮输入转换为平滑的运动曲线。

    Input输入Wheel action滚轮动作

  2. Stop Inertia

    停止惯性

    Use a small interrupt when you want the current glide to stop. Default keyboard braking uses L_SHIFT and R_SHIFT, and those keys can be customized.

    想让当前惯性立刻停下时，使用一个轻量的中断动作。默认键盘停止使用 L_SHIFT 和 R_SHIFT，这些按键可以自定义。

    MethodActionNote
    方式输入顺序备注
    Reverse wheel反向滚轮 Wheel action滚轮动作>Reverse wheel反向滚轮 Best for quick stops.适合快速停止。
    Mouse button鼠标按键 Wheel action滚轮动作>Any button任意按键 Except Free Spin.不包括 Free Spin。
    Mouse movement鼠标移动 Wheel action滚轮动作>Mouse move鼠标移动 Useful during pointer moves.适合移动指针时使用。
    Keyboard键盘 Wheel action滚轮动作>Key press/release按键按下/释放 Default: Shift keys.默认：Shift 键。

  3. Passthrough

    Hold a passthrough key when the application should receive raw wheel events, for example browser zoom or editor shortcuts. Defaults: Ctrl and Super, both customizable.

    当应用需要接收原始滚轮事件时，按住透传按键，例如浏览器缩放或编辑器快捷操作。默认按键：Ctrl 和 Super，都可以自定义。

    Input输入Hold Ctrl / Super按住 Ctrl / Super>Wheel action滚轮动作

  4. Free Spin

    Use Free Spin for long pages or timelines when you want a steady cruise without automatic deceleration. Default button: right mouse button, customizable.

    在长页面或时间线上需要持续巡航滚动时使用 Free Spin，此时不会自动减速。默认按键是鼠标右键，可以自定义。

    Input输入Wheel action滚轮动作>Right press右键按下>Wheel action滚轮动作>Right release右键释放

  5. Drag View

    Use Drag View when you want mouse movement to pan content, including horizontal movement. It can be available only while scrolling or at any time. A quick press is replayed as a normal click. Default button: middle mouse button, customizable.

    希望用鼠标移动来平移内容时使用 Drag View，也可以处理横向移动。它既可设为仅滚动时可用，也可设为始终可用；快速按下松开仍会补发为普通单击。默认按键是鼠标中键，可以自定义。

    Input输入Wheel action滚轮动作>Middle press中键按下>Mouse move鼠标移动>Middle release中键释放

Extensions

扩展

Install the extension for your desktop if you want to see the current scroll state near the pointer, stop inertia when you leave a window, or set windows that should always receive raw wheel events.

如果你想在指针旁看到当前滚动状态、离开窗口时自动停止惯性，或设置哪些窗口始终接收原始滚轮事件，请安装对应桌面环境的扩展。

  • See whether Smooth Scroll is scrolling, in Drag View, or passing wheel events through.
  • 看清当前是平滑滚动、Drag View，还是滚轮事件透传。
  • Stop the current glide automatically when the pointer moves out of the window.
  • 指针移出当前窗口时，自动停止正在进行的惯性滚动。
  • Add window rules for places where smoothing should always be bypassed.
  • 为需要始终绕过平滑处理的窗口添加规则。

Customization

自定义

  1. Open the configurator

    打开配置器

    Go to the Customization page.

    进入自定义页面。

  2. Adjust and export

    调整并导出

    Edit the settings, then copy TOML or download smooth-scroll.toml.

    调整设置后，复制 TOML 或下载 smooth-scroll.toml。

  3. Apply the config

    应用配置

    Replace the system config, then restart the service.

    替换系统配置文件，然后重启服务。

    sudo cp ~/Downloads/smooth-scroll.toml /etc/smooth-scroll/smooth-scroll.toml
sudo systemctl restart smooth-scroll.service
